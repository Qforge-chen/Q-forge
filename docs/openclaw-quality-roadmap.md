# Project Roadmap

## Current State

Q-Forge already runs as a local quality workflow system with four core capability packages:

- `8D`: report intake, deterministic gates, audit verdicts
- `rootcause`: constrained RCA reasoning
- `reporter`: decision-ready HTML rendering
- `supplier`: IQC and supplier quality monitoring

## What This Public Release Shows

This repository release now shows a larger migration result:

- `8D` mobile proof is complete
- `RCA` mobile proof is complete
- `Supplier` mobile proof is complete
- `Reporter` is proven through the rendered HTML artifacts across all three flows

## Why This Scope

The immediate goal is not a full product release. It is a compact public engineering proof for review and follow-on builders:

- real package code
- short demo media
- sanitized public inputs
- saved outputs from local runs
- rendered reports
