# Hackathon Roadmap

## Current State

Q-Forge already runs as a local quality workflow system with four core capability packages:

- `8D`: report intake, deterministic gates, audit verdicts
- `rootcause`: constrained RCA reasoning
- `reporter`: decision-ready HTML rendering
- `supplier`: IQC and supplier quality monitoring

## What This Public Pass Shows

This repository pass is intentionally narrow.

- `8D` is the main proof chain.
- `RCA` is the second proof chain.
- `Reporter` is proven through the rendered 8D and RCA HTML outputs.
- `Supplier` stays visible as a real package, but does not take example slots in this pass.

## Why This Scope

The immediate goal is not a full product release. It is a fast public proof layer for Hackathon review:

- real package code
- short demo media
- sanitized public inputs
- saved outputs from local runs
- rendered reports

## Next After Submission

- Expand supplier public examples
- Add a cleaner public installation story around the local host runtime
- Publish more cross-skill evidence without exposing private working memory
