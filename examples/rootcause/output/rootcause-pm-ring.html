缺陷形成机制
第 1 步：压制阶段（Compaction）
压力过大 +30%
→ 绿坯内部产生高残余应力
→ 密度分布不均（无台阶端面应力更集中）
→ 可能产生微裂纹/层裂（目视不可见）
第 2 步：烧结阶段（Sintering）
→ 残余应力部分释放，但缺陷已固化
→ 微裂纹无法通过烧结消除
→ 密度梯度保留
第 3 步：整形阶段（Sizing）
→ 整形载荷作用在已有缺陷的绿坯上
→ 微裂纹扩展（但仍目视不可见）
→ 无台阶端面承受更大应力（结构不对称）
第 4 步：客户装配阶段
→ 装配应力触发裂纹扩展
→ 裂纹显性化（渗透检测发现）
→ 50% 不良率（批次性异常）

为什么只有无台阶端面开裂？

因素 分析
结构不对称 有台阶端面刚性更强，无台阶端面更薄弱

密度梯度 无台阶端面密度不均更严重
